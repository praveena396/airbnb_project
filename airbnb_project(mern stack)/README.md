# Airbnb Project

An Express and EJS application organized with an MVC structure.

## Setup

1. Install dependencies with `npm install`.
2. Copy `.env.example` to `.env` and set `MONGODB_URI` and `SESSION_SECRET`.
3. Start the app with `npm run dev`.
4. Open `http://localhost:3003`.

Use `npm start` to run without nodemon. Run `npm run tailwind` in a separate terminal while developing styles, or `npm run tailwind:build` for a one-time CSS build.

## Project structure

- `controllers/` handles request workflows.
- `models/` contains database models.
- `routes/` maps URLs to controllers.
- `views/` contains EJS templates and Tailwind input styles.
- `public/` contains static assets and generated CSS.
- `utils/` contains shared utilities.
- `uploads/` stores uploaded images.
